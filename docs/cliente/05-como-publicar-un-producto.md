# Cómo publicar un producto

El proceso siempre es el mismo:

```
Crear el producto  →  Añadir fotos  →  Elegir cuentas
    →  Ver la vista previa  →  Confirmar  →  Publicado
```

## Paso 1: crear el producto

1. Entra en **Productos**
2. Pulsa **Nuevo producto**
3. Rellena los datos:

| Campo | Ejemplo | ¿Obligatorio? |
|---|---|---|
| Nombre | Canapé abatible 135x190 Gris | Sí |
| SKU | (déjalo vacío y se crea solo) | No |
| Tipo | Canapé abatible | Recomendado |
| Categoría | Hogar y jardín | Sí |
| Medida | 135x190 | Recomendado |
| Color | Gris | Recomendado |
| Material | Madera | Recomendado |
| Estado | Nuevo | Recomendado |
| Precio | 269,00 € | Sí |
| Stock | 5 | Recomendado |
| Descripción | Texto propio del producto | Sí |

4. Pulsa **Guardar**

## Paso 2: añadir fotografías

1. Selecciona el producto
2. Pulsa **Fotografías**
3. Elige las fotos (JPG, JPEG, PNG o WEBP)

LOT Bot comprueba cada foto y te avisa si:

* El formato no vale
* La foto está repetida (la descarta automáticamente)
* La resolución es baja

La primera foto es la principal.

## Paso 3: elegir en qué cuentas publicar

1. Con el producto seleccionado, pulsa **Asignar a cuentas**
2. Marca las cuentas
3. Pulsa Aceptar

## Paso 4: revisar la calidad

Al seleccionar el producto, el panel de la derecha te dice si se puede publicar:

* **Errores** (en rojo): impiden publicar. Hay que corregirlos.
* **Avisos**: no impiden publicar, pero conviene mirarlos.

Errores típicos:

| Error | Solución |
|---|---|
| El anuncio no tiene precio | Pon el precio |
| No tiene ninguna fotografía | Añade fotos |
| Falta la categoría | Rellena la categoría |
| El título contiene variables sin rellenar | Completa los datos del producto o revisa **Configuración → Negocio** |
| La medida del título no coincide con la ficha | Corrige la medida |

## Paso 5: ver cómo quedará

Pulsa **Vista previa**. Verás, para cada cuenta, el título, la descripción completa y
el precio tal y como se van a publicar.

## Paso 6: publicar

1. Pulsa **Publicar**
2. Lee el resumen: qué se va a publicar y en qué cuentas
3. Pulsa **Confirmar**

Al terminar verás el resultado de cada cuenta. Si Wallapop rechaza alguno, te dice el
motivo; no se oculta nada.

## Publicar desde el asistente

También puedes decirle al asistente:

```
Prepara la vista previa de "CAN-135X190-GRI"
```

Y te la enseña sin publicar nada.

## Preguntas frecuentes

**¿Puedo publicar el mismo producto en varias cuentas?**
Sí, para eso está «Asignar a cuentas». Se crea un anuncio en cada una.

**¿Se publica automáticamente?**
No. Nunca se publica nada sin que tú lo confirmes.

**¿Y si me equivoco?**
Puedes modificar el anuncio desde **Anuncios** o eliminarlo (te pedirá confirmación,
porque eliminar no tiene vuelta atrás).
